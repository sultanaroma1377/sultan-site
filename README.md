# sultan site

Create a website for my perfume business in there must be two panels

One for User with following details:

Header for logo business name, three horizontal lines on right and cart icon to go to cart

Card for title and tagline etc..

Products in grids with name of product and price and and star icon to add to favorite and cart icon to add to cart and search bar on top of products

Footer for social media, website and location links and address 

And add to favorite and add to cart must work only after login so it can be saved to database for their account 

And account details, login/ logout must be in three horizontal lines on header

In account details there must be addresses and option to edit them

Second Admin panel with following details: 

There must be following tabs,

Site management: in this there must be option to add site name, site logo(upload from device not url), admin credentials to change username or password of admin and option to add new admins, option to add social media links, location link, website link and address.

Product management: in this tab there must be option to add products manually and by syncing from google sheets by adding api and sheet id and to edit any product.

Customer: in this tab there must be option to see customer's activity means there must be list of customers, on selecting any customer it must show items added to favorite and added to cart.

Cart: in this there must be added items in cart with option to save any item for later so it must not there in this cart.

After checkout order from cart there must be option to select or add address(if not added before) with one text box for flat no., building, area next for pincode next for state next for city(on adding pincode it must automatically detect state and city)

After address next step to add receiver's name and number and confirm button on clicking it message must appear that after order is accepted u will be informed to pay amount.

Coupons: in this tab there must be option to create coupon code with option to add amount so above that amount's purchase the coupon must apply.

Confirmed carts: in this tab there must be Confirmed cart from customer means when customer make an order and confirm it must show here and there must be option to accept it and there must be option to print address so it must save in a5 size and also option to select orders to print their addresses(with name and number) in combined pdf so on every page there must be two address in a4 page means every address in a5 size with business address and number in "from" so it can be printed and pasted for courier
